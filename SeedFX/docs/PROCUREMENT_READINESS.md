# 单台成品：采购前复核

**当前状态：软件与数字工程可构建，采购冻结尚未完成。** 现有装配、开孔和供应商清单需要继续复核，不能把“编译/DRC 通过”视为整机装配与采购均已确认。唯一一台设备在调试验收后作为最终成品。

## 此次查出的明确问题与修正

- 电源口：旧壳体侧孔使用居中 X=33mm，而当前 Rev6 PCB 的 J1 Fabrication 外形轴线为正视 X=42.57mm，旧横向孔位相差 9.57mm。STEP、侧孔 CSV 和布局数据现已按该轴线修正；安装高度 Z=22mm 仍须依据实际器件安装栈核对。
- 音频接口标注：PCB J2 为右侧输入、J4 为左侧输出，侧孔 CSV 已修正；两孔几何尺寸相同。
- 装配 BOM：原表中的 R9-12、R21-25、R26-29 已展开为各个器件编号，增加 Quantity 列。新增检查用导出的 KiCad 网表验证编号存在、无重复、数量一致。
- XIAO 附件包络长边取 21mm、短边修正为 17.8mm。包络检查仍未覆盖供应商实际高度、焊点和线束。

## 下单前尚需关闭的设计与采购事项

1. **完整装配核对**：为选定的 Seed/排针、插座、屏幕、脚踏和外壳补齐安装尺寸，检查高度、公差、USB 接入口、螺母、线束与 RF 天线。当前 CAD 只检查裸板与附件包络，主控深度≤28mm 是采购假设，尚未以完整元件模型证实。
2. **主板 ERC 注记复核**：报告中有 115 个网格警告、9 个 NC 注记与实际连接不符、1 个悬空线端。其中 A1 的 USART1 TX/RX 现在用于无线，图纸上的 NC 语义需要更新。DRC 与网表一致性通过可以证明铜层连接一致，不能替代对图纸意图的复核。
3. **电源选型与装配方式**：明确具体 Mini-360 商品的尺寸、输入/输出额定条件与调节固定方法。用户没有工具，按 [手焊方案](DIY_BUILD_OPTIONS.md) 计入基础工具与练习耗材；练习后仍可选择只代焊主板贴片。电压、纹波、噪声、过冲和温升在同一台设备组装时实测。
4. **单台完整报价**：当前全手焊加通用铝壳/外包开孔预算 ¥833.9–1801.5，全手焊加打印壳预算 ¥778.9–1636.5，均含新购工具；[逐项委托制作预估](PURCHASING_PRICES.md) 留作历史对照。实际物料最低包装、裸板订单、工具与外壳制作尚未取得完整成交报价；具体壳体安装和打印受力结构也未完成验证。
