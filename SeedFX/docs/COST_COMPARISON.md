# 相比原仓库增加了哪些成本

此前 ¥848.9–2006.5 是按独立采购与委托制作列出的工程预算，不是原作者的当期造价，也不是供应商给我们的报价。本方案目前没有证明比市售 NAM 成品更便宜。当前按用户选择方向改为自行焊接、通用铝壳或打印壳，并计入新购工具，见 [制作路线对比](DIY_BUILD_OPTIONS.md)；下表保留此前预算的成本来源分析。

明确新增的材料为 ¥89.5–227.5，加适配板焊接后为 **¥99.5–257.5**。RF 窗口额外开槽费用混在壳体加工额度中，尚未取得单独报价。这个区间不是实际成交差价。

上述“原设计主体”是我们的当前估价按来源分组，不能据此断言原作者整机造价就是 ¥489–899；原作者完整 MIDI 装配和 LED 支架等与本项目也有差别。

## 原方案的已知资料

- Rev6 已有六旋钮、OLED、按压编码器、双脚踏、双声道模拟接口与继电器旁通，主控为现成 Daisy 开发模块。这些功能的硬件费用并非本次软件功能新增。
- 原教程让用户自行完成电位器、编码器、屏幕、脚踏等通孔焊接和装壳。按自己已有工具/自行装配的口径，没有本预算列出的全部外包工费。
- 原教程的 **Rev5 历史报价截图**显示，结合正文所述的 5 块已贴片主板订单，总计 **$107.77**，算术平均约 **$21.55/块**。这只是历史 PCBA 订单，Daisy、控制件和外壳等仍另买，也不能作为当前单台订单报价。

## 应如何处理降本

当前主要价格项是 Daisy 开发模块（预估 ¥240–360）以及分项外包制作。NAM 推理、效果链、自定义旋钮映射和手机 UI 沿用现有主控，不额外增加这些软件功能的物料成本。

建议先暂停完整采购，拿到单台整板/整机装配报价和指定料号的实际售价，再调整制作路线：

1. 比较单台整体代焊报价，合并已包含的 SMT、通孔件和线束费用。
2. 评估保留 Wi-Fi、采用短线 UART 和小块滤波电路的实现，减少独立适配板最低订单与贴装起步费；这是待设计复核的候选，不是已经验证可直接替换的接线方案。
3. 使用现成标准壳与一次贴图/转印；RF 天线位置与实际安装尺寸确认后，再决定最少的开孔和打印件。
4. 继续评估单声道是否值得简化原双声道/继电器电路。修改主板需要重做设计与验证；不能直接在现有 BOM 中随意删件。

只做一台的定制 DIY 通常难以获得量产成品的采购和装配成本。这个项目的价值是可改代码、自定义操作和外观；预算优化必须靠明确的取舍与实际报价，不能再靠未询价的低端估值承诺便宜。
