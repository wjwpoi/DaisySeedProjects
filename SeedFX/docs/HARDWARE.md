# 硬件、采购与制造

## 单台制作与采购

本项目只装配一台，调试完成后即作为最终成品。PCB、贴片或代焊、开孔与印刷按单台项目询价，最低订单和一次性服务费全部计入项目预算；供应商交付的多余裸板留作维修备件。采购数量表描述这台设备装入的数量，实际下单数量需结合最低订单与维修备料确定。

## 两块板及无线模块

主板复用仓库 125B Rev6 的电路、铜层和连接。工程包补齐项目本地符号/封装库，把冲突的丝印文字与轮廓移到 Fabrication/Dwgs 层；电路连接与焊盘位置没有改动。新增 32×28mm 两层适配板提供无线电源滤波、UART 串联电阻和可拔插连接。

全部 GPIO 对照见 `io-map.csv`。

主板名义电路仍包含 MIDI。SeedFX 的默认装配不焊 `J3,J5,U4,D2,R17,R18,R19,R20,C17`，且固件不初始化 MIDI。USART1 用于无线；不应把参考 MIDI 固件同时接入这套 UART。

| 关键件 | 选择与理由 |
|---|---|
| 主控 | Daisy Seed Rev7，复用音频 codec 和内存，降低首版电路与软件风险 |
| 输入缓冲 | 参考 MCP6004T-I/SL 与现有高阻抗输入网络 |
| 输出缓冲 | 参考 OPA1652AIDR；mono TS 音频接口 |
| 电位器 | Alpha RD901F-40-15R1-B10K，六只；封装与参考主板匹配 |
| 编码器 | Bourns PEC11R-4220K-S24，带按压开关 |
| OLED | 0.96 英寸 128×64 SSD1306 七针 SPI；参考 PCB 外框约 27.5×27.75mm，活动区约 22×11mm |
| 无线 | Seeed XIAO ESP32-C3，外置 IPEX 天线；GPIO21 TX、GPIO20 RX 已对照 Seeed 官方 pinout |
| 无线供电 | Mini-360 MP2307DN 小板，标定并固定到 5V；使用保护后的 +9V 输入；按至少 0.5A 连续输出验收 |
| 固定电压替代 | Pololu D24V10F5 #2831，5V/1A；接线相同，预算增加约 ¥60–85 |
| 电源滤波 | BLM21PG601SN1D 磁珠、两只 22µF/10V X5R 1206、一只 100nF/50V X7R 0805 |
| UART 保护 | 两只 1kΩ 0805 串联电阻；接口仍是 3.3V TTL，不是 RS232 |

完整零件和原始 LCSC 选择在 `purchase-bom.csv` 与 `mainboard/assembly-bom.csv`。`adapter/bom.csv` 给出适配板装配明细。库存、价格和供应商替代料未实时询价；需要核对封装、引脚和机械尺寸，不能只按相同商品名称替换。

## 接线与供电

逐项按 [wiring.csv](../hardware/wiring.csv) 执行。Daisy TX 接无线 RX，Daisy RX 接无线 TX，所有逻辑均为 3.3V。

| Daisy 点位 | 主板焊点 | 对应适配板 |
|---|---|---|
| D13 / PB6 / 物理 14 脚 | J7-7 | J3-2，SEED_TX |
| D14 / PB7 / 物理 15 脚 | J7-6 | J3-3，SEED_RX |
| GND | J7-1 | J3-1 |

无线降压板从主板 C1 正端、D1 后的受保护 +9V 取电。其 5V 输出经适配板滤波送 XIAO VBUS/5V。不要将无线负载挂到主板 LD1117 的模拟 5V 轨上。UART/GND 线保持短，远离音频输入，模块电源回流回到电源入口。

Mini-360 在接 XIAO 前，用万用表和负载标定到 5.00V。检查 9V 输入下从空载到 0.5A 的电压、启动过冲与纹波；合格后固定调节器并贴 5V 标签。无法满足指标时使用固定输出替代模块。此过程尚未执行。

USB 烧录时拔掉外部 9V，并断开可拔插 UART 线束。两块主控独立 USB 供电时不通过 GPIO 互相供电；XIAO 的 VBUS 不与另一 5V 电源同时接通。重新合壳前恢复线束。

## PCB 制作

- FR4，主板按原工程 1.6mm，适配板 1.6mm；两层，1oz 铜，常规阻焊。
- 两块板均需检查发布包中的 Gerber、钻孔和装配图；主板器件标号主要在 Fabrication 图上。
- 主板采购依据筛选后的装配 BOM。贴片坐标文件保留参考编号；默认 MIDI DNP 由装配 BOM 明确标记，不凭坐标文件自行补焊。
- 适配板电源/回流采用宽铜线，信号线约 0.3mm；成品接插件要明确 Pin1。
- 原理图检查：适配板零 ERC 违规；参考主板没有 ERC 错误，但保留历史图纸的 off-grid、未用连接器 NC 标记及线端警告，详见验证说明。两块 PCB DRC 和网表一致性均为零问题。

参考主板的 Alpha 电位器底部金属支脚可能接触 Daisy 座针，尤其 POT4–POT6。按照原作者装配说明去除靠近座针的金属支脚，或加可靠绝缘；断电测量确认没有意外导通。OLED 参考安装使用约 6mm 尼龙垫柱，需要按实际器件和前面板位置核对高度。

## 外壳与无线窗口

`mechanical/` 提供完整 STEP、分件 STL、前面板 DXF/CSV、侧面开孔 CSV、默认印刷 SVG、可替换封面模板和机器尺寸数据。坐标为面板正视：X 向右，Y 向下，Z 向后盖。

旋钮/编码器轴心按主板 Fabrication 圆心变换：`front_x = 175 - pcb_x`，`front_y = pcb_y - 37.5`。第二排旋钮 Y=40.5mm，编码器 Y=81.275mm，避免沿用另一版外壳孔距。OLED 开窗按当前 0.96 英寸模块活动区为 23×12mm。

右侧 40×17mm 非金属 RF 窗口对应外置天线；不要用金属箔、金属漆或铝壳盖住天线。壳体外尺寸为 66×121.5×42mm，壳体本体 38.5mm、盖板 1.5mm，再加独立 2mm 增高隔圈；隔圈提供 STEP/STL，可用低成本 PETG 制作。现成壳体仍需按实际内腔核尺寸。托盘贴合后盖内侧；适配板使用两个 M2、2mm 高的绝缘支撑，其孔位由板孔直接确定。XIAO 与 Mini-360 使用绝缘胶垫固定，按 `accessory-placement.csv` 摆放；适配板含接头厚度不超过 7.6mm，XIAO 不焊排针、厚度不超过 4mm，降压模块不超过 18×14×4mm。附件与主控深度 28mm 的采购避让区至少间隔 1.7mm。模块通过绝缘托盘固定在后盖内侧；尽量保留天线与 PCB/金属的距离，并验证实际装配后连接效果。

CAD 已检查裸主板、附件包络与壳体/后盖无实体干涉，附件之间也无重叠；完整装配 STEP 包含托盘、增高隔圈和 RF 窗口；盖板与本体/隔圈也无实体重叠。器件外形、焊点、螺母、线束、底盖、公差与供应商壳体内腔仍须实物核对。标准 125B 现成壳的壁厚、拐角和螺丝柱可能不同，不能仅因名称相同就直接照孔位加工。

印刷使用 `panel-print.svg`；替换图案使用模板的 `custom-artwork` 图层，保留孔位、硬件避让与文字图层。默认设计为深色壳、浅色标识和克制的波形纹理；可在收到你的封面后换图层。
