# SeedFX 用户手册

## 开始演奏

1. 吉他用 mono TS 线接输入；输出用 mono TS 线接音箱、FRFR 或声卡的合适输入。没有耳机功放。
2. 接 9V 中心负、至少 1A 的电源。开机恢复上次显式保存的槽位；首次为 P01。
3. 从较低输出音量开始。若 CLIP 或琥珀 LED 持续点亮，降低 Input/Output 并检查输入端是否已过载。
4. 旋钮前一秒等待 ADC 稳定。调用预设或手机改值后，旋钮转到当前参数位置才接管，避免突然跳值。

接 FRFR/声卡时，DI 箱头模型通常需要箱体 IR；已含箱体/麦克风的捕获应关闭额外 IR。接真实吉他箱体/后级通常关闭箱体 IR；接传统音箱前级可关闭 NAM，只用其他效果。

## 本机控制

| 操作 | 行为 |
|---|---|
| 默认六旋钮 | 第一排 Input、Bass、Mid；第二排 Treble、Level、User（默认 Delay Mix） |
| 编码器旋转，选择模式 | 选择待编辑参数 |
| 编码器短按 | 切换选择/编辑模式 |
| 编码器旋转，编辑模式 | 改当前参数、模型或效果开关 |
| 编码器按住约 1 秒 | 保存到当前槽位；成功后 `*` 消失 |
| 左脚踏短按并释放 | 数字旁通；调音模式下退出调音 |
| 左脚踏按住约 0.7 秒 | 开关调音器，调音时静音 |
| 右脚踏短按 | Tap Tempo；两次点击间隔设置延迟时间 |
| 右脚踏按住约 0.7 秒 | 切换下一预设，P16 后回 P01 |
| 绿色 LED | 效果链工作，数字旁通时灭 |
| 琥珀 LED | 切换忙碌或电平过载；过载提示保持约一秒 |

OLED 显示槽位、未保存标记、模型、当前参数、CPU 平均/峰值及 CLIP。调音以 A4=440Hz 为基准。编码器和脚踏时长须在实机确认。

## 手机控制

连接设备的 `SeedFX-XXXX` Wi-Fi，初始密码 `seedfx123`。在浏览器访问 **http://192.168.4.1/**。网络是效果器本地 AP，不需要互联网或 App。

顶部显示当前音色与预设、输入/输出电平和 CPU。各效果卡提供开关和参数；自定义旋钮页面可将连续参数映射到六只旋钮，并随预设保存。目标槽位下拉框用于载入或保存，和顶部“当前槽位”分别显示。

“设置已确认”表示音频主板已接受参数；模型切换期间显示忙碌。“预设已写入并校验”只在实际存储确认后出现。连接失效时按钮禁用，不发送离线设置；本机音频与物理控制继续工作。

保存会短暂淡出，并暂停音频以完成闪存擦写。切换/调参不自动写闪存，降低写入次数。旁通和调音状态为临时状态，不随预设保存；开机默认运行效果链。

## 预设起点

P01 BE-100，P02 JCM800，P03 Ampeg，P04 Mesa，P05 1959BJA；P06 合唱，P07 Slap，P08 Lead Delay，P09 Ambient，P10 Overdrive，P11 Bass，P12 Compress；P13–P15 提供基础无 NAM 链/合唱/延迟，P16 用户起点。它们供开始调参，尚未实机试听及统一响度。
