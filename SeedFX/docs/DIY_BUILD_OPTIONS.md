## 当前选择方向

优先评估自行焊接、淘宝通用铝壳、简单贴纸封面；PETG打印壳作为候选。铝壳适合长期踩踏，但必须核实实际内腔、装配深度与天线位置。打印壳需要完成承重结构设计后才能制作。这里只修改制作路线与预算，没有宣称外壳结构已经重新验证。

## 能否全手焊

核对当前PCB封装与装配BOM，主板实际安装的贴片件54颗：43颗0805阻容、3颗SOD二极管、2个贴片继电器、2个SOIC运放、2个SOP-4光继电器、1个SOT-23晶体管、1个SOT-223稳压器。适配板还有6颗0805/1206贴片件和3个排针。

这些外围封装具备烙铁手焊条件，没有需要用户自己焊接的BGA/QFN主控；Daisy、XIAO、OLED与降压模块整块购买。SOIC焊桥、器件方向、继电器焊点和小件极性仍需逐个检查，不能把模块插接等同于全部免焊。

取消主板SMT、适配板焊接、通孔与线束代焊，可去掉原预算人工 **¥160–480**。购置工具增加¥180–350，首台的净节省取决于实际工费和工具成交价，不保证全手焊必然比局部代焊便宜。若练习后难以稳定焊好SOIC，可只询价主板贴片，自己焊外围；从对应路线预算另加实际贴片报价，不能套用包含通孔装配的旧整机工费。

建议顺序：练习0805/SOIC → 焊主板和适配板低矮贴片件 → 焊排母与通孔件 → 断电检查短路及电位器金属脚绝缘 → 不插主控先检查供电，标定Mini-360到5V → 接入模块烧录与裸机验收 → 按实际装配位置加工/打印壳体。接线、供电和USB限制继续按 [硬件说明](HARDWARE.md) 执行。

## 外壳与外观

- **铝壳**：普通现成壳体与贴纸即可做完整封面，不默认烤漆、UV直印或整壳CNC。现有PCB安装位置决定孔距；通用壳体的尺寸、螺柱和壁厚必须核实，增高隔圈预算仍保留。
- **无线**：金属壳需要非金属天线窗口或在壳外保护放置天线，方式待复核；不能将天线完全封在金属盒里并假定连接正常。
- **PETG打印壳**：开口与安装柱可一体打印，省去金属壳加工；脚踏附近需要肋、厚壁或金属加强板，并使踩踏载荷传到壳体/底板，避免靠PCB承重。打印层方向、紧固方式与实际受力仍需验证。
- **屏蔽**：金属壳按原设计接地；塑料壳可评估局部导电屏蔽并接地，但需要给天线留非导电区域，新增屏蔽材料据实计价。
- **现有STL**：是当前尺寸与孔位的参考模型，没有做整壳打印承重、耐热和长期踩踏验证，不能作为最终打印下单依据。
