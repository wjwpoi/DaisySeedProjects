| PCB | 两块板 DRC 无违规、无未连接项、无网表一致性问题；适配板 ERC 无违规 |

## 唯一一台设备的成品验收表

| 项目 | 方法与判定 |
|---|---|
| 电源 | 接主控前检查极性/短路；9V 输入，标定 5V；0–0.5A 负载、开关机和瞬态检查；无越过 MCU 允许范围的电压 |
| 旋钮与数字输入 | 六 ADC 全行程、编码器两个方向/按压、两脚踏长短按；确认没有支脚碰到 Seed 针座 |
| 屏幕 | SSD1306 SPI、列/行完整、开孔不遮活动区、字号与户外可读性 |
| 音频电平 | 1kHz 已知电压信号测输入满量程与输出；确认 codec 前不过载，旁通与启用响度可控制 |
| 延迟 | 用环回录音测 NAM/EQ/IR 路径；记录首次响应和峰值/群延迟，目标小于5ms |
| 实时预算 | 所有效果、各模型、最大反馈、屏幕刷新及 Wi-Fi 连续调参；回调最大耗时低于1ms，目标留25%余量，无丢块 |
| 换模 | 五模型至少100次切换，记录静音窗口及是否有明显爆音；目标小于20ms，不能用解析初始化主机测试代替 |
| 同模型预设 | 比较声音、旋钮拾取、启停与尾音；连续参数更新不重载权重 |
| 保存与断电 | 两银行轮换；写入过程中断电后恢复旧有效或新完整银行；保留至少一个有效配置；验证重启槽位 |
| 调音 | E2–E4 六弦与单音，A4=440；目标稳定状态±5 cents，避免泛音倍频误判 |
| 无线与噪声 | 天线装入实际壳体后，5m连接与重连；Wi-Fi开/关录音对比，检查电源和RF串入的噪声 |
| 长时间运行 | 至少60分钟最坏链路，记录温升、供电电流、重连、CPU峰值及音频异常 |
| 机械 | 原料壳与实际器件核尺寸；盖合、螺母、螺柱、焊点、USB口、线束、绝缘及跌落后的固定情况 |

在这唯一一台设备上完成组装、测量、修正和验收。若实测不满足设计指标，按记录修改具体 DSP、供电、天线或结构；达到验收目标后，该设备即为最终成品。
